# Security policy

## English

This repository publishes a research checkpoint. There is no supported product version and no security-patch cadence.

**Do not use this model as a medical device**, for emergency triage, or as the sole basis for clinical decisions. Fabricated doses, diagnoses, guidelines, or citations are expected failure modes, not out-of-scope surprises.

### Reporting a vulnerability

Please use [GitHub Security Advisories](https://github.com/rwang220/yida_model/security/advisories/new) for:

- secrets accidentally committed to this repo
- unsafe default scripts that could leak credentials
- issues that should not be discussed in a public issue first

For model-quality problems (hallucinations, bad medical advice, eval gaps), open a public issue instead. Those are capability limitations, not security vulnerabilities.

We will acknowledge private reports when we see them. There is no SLA.

## 中文

本仓库发布的是研究用 checkpoint，没有产品化版本，也没有定期安全补丁。

**不要把本模型当作医疗器械**，不要用于急救分诊，也不要单独作为临床决策依据。编造剂量、诊断、指南或文献是预期失效模式。

### 如何报告漏洞

请通过 [GitHub Security Advisories](https://github.com/rwang220/yida_model/security/advisories/new) 私下报告：

- 误提交的密钥
- 可能泄露凭据的脚本默认值
- 不宜先在公开 issue 讨论的问题

模型质量问题（幻觉、错误医疗建议、评估缺失）请开公开 issue。那是能力限制，不是安全漏洞。

收到私下报告后会确认，但没有约定处理时限。
